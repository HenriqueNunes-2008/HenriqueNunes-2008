## 💻 Projetos em destaque

### 📊 Sistema NPS

Aplicação web desenvolvida para digitalizar o processo de entrega e avaliação de projetos.

O sistema gerencia diferentes etapas do processo, permitindo termos de aceite, ressalvas, recebimento, treinamento, assinaturas digitais, avaliações NPS/eCSAT e geração de documentos em PDF.

**Tecnologias:** Python • FastAPI • PostgreSQL • Supabase • HTML/CSS/JavaScript • Render

[Ver repositório →](https://github.com/HenriqueNunes-2008/SistemaNPS)

---

### ⏱️ Registro de Horas por QR Code

Sistema web para registro e acompanhamento de horas trabalhadas através de QR Codes.

Permite relacionar **funcionários, áreas, projetos e atividades**, facilitando o apontamento e acompanhamento das horas executadas.

**Tecnologias:** Python • Flask • PostgreSQL • SQLAlchemy • QR Code

[Ver repositório →](https://github.com/HenriqueNunes-2008/registro-horas-qr)

---

### 📦 Saída de Materiais

Aplicação desenvolvida para digitalizar o registro de saída de materiais e melhorar o controle das movimentações do almoxarifado.

O projeto substitui controles manuais por um fluxo centralizado, permitindo registrar e consultar movimentações e gerar informações para acompanhamento.

**Tecnologias:** Python • Flask • PostgreSQL • HTML/CSS • Render

[Ver repositório →](https://github.com/HenriqueNunes-2008/saida-de-materiais-web)

---

### 📝 Justificativa RH

Aplicação interna criada para digitalizar o processo de justificativas de ponto.

Permite o preenchimento das informações pelo colaborador, assinatura digital e consulta dos registros pelo RH.

**Tecnologias:** Python • Flask • PostgreSQL • Neon • HTML/CSS/JavaScript

[Ver repositório →](https://github.com/HenriqueNunes-2008/justificativa-rh)

---

### 🧾 Notas Fiscais

Aplicação para registro e organização de informações relacionadas a notas fiscais, centralizando os dados utilizados no processo interno.

O sistema utiliza integração com **Google Sheets** para armazenamento e acompanhamento das informações.

**Tecnologias:** HTML • CSS • JavaScript • Google Sheets

[Ver repositório →](https://github.com/HenriqueNunes-2008/Notas_Fiscais)
